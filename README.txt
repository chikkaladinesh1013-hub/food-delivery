CRAVE — FOOD DELIVERY WEBSITE
=============================

FILES
-----
index.html  Main webpage structure
style.css   Responsive layout, colours, cards and mobile styling
script.js   Search, category filters, cart, quantity controls, coupon copy and demo messages

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the Food_Delivery_Website folder.
3. Double-click index.html to open it in a modern browser.
4. For best results, use an internet connection so the Google Font and food photos can load.

FEATURES
--------
- Responsive food-delivery landing page
- Restaurant cards with ratings, delivery times and offer labels
- Food categories with interactive filters
- Popular dish cards with prices and Add buttons
- Search dishes by name
- Shopping cart with quantity controls and subtotal
- Promotional coupon with copy button
- Mobile navigation menu
- Demo checkout and toast notifications

IMPORTANT
---------
This is a front-end learning/demo project. It does not connect to a real restaurant,
delivery service, payment gateway, or database. Orders are not submitted or stored.
Restaurant names, menu items, prices, offers and location are sample content.
Food images are loaded from Unsplash and require internet access.
